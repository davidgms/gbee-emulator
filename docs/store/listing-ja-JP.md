## Full description (1385/4000)

```
GBeeはスマートフォン向けに作られたGBAエミュレーターです。案内役はサングラスをかけたハチのGB。自分のゲームが入ったフォルダを追加するだけで、すぐに遊べます。

🎮 GBAゲームをプレイ
• Rustで書かれた高精度なエミュレーションコア。公開されているハードウェアテストスイートで検証済み
• 低遅延のサウンドで、ゲームはフルスピード
• 早送りは2倍、4倍、8倍、無制限から選択

🕹️ ボタンを自由に配置
• ボタンを1つずつドラッグしてサイズを変更
• 縦画面と横画面で別々のレイアウト
• 複数のレイアウトを保存して切り替え

🧩 オリジナルボタンを作成
• コンボ：1本の指で複数のキーを同時押し
• シーケンス：キーを順番に1つずつ入力
• ホールド切替：1回タップでキーを押したままに、もう1回タップで離す

🎨 色を選ぶ
• ボタンテーマ：ナイト、ハニー、バイオレット、クラシックグレー
• ボタンのサイズと不透明度を手に合わせて調整
• 押すたびに振動フィードバック

💾 どこでもセーブ
• 上部バーからクイックセーブとクイックロード
• さらに7つのセーブスロット、それぞれ日時つき
• 巻き戻し：ボタン長押しで数秒前に戻る
• クイックセーブからそのままゲームを再開
• ゲームのセーブデータは安全に書き込まれるため、クラッシュやストレージ不足でも破損しません
• 他のエミュレーターのセーブデータ（.sav、.srm、.sa1）を読み込み、自分のデータを好きなフォルダに書き出し

✨ 見た目をカスタマイズ
• 画面フィルター：ピクセルパーフェクト、スムーズ、CRTスキャンライン、2xSaI
• 整数倍スケーリングでくっきりしたドット
• フレームブレンドで、ちらつきを実機の画面のように再現

🏆 実績を獲得
• RetroAchievementsを内蔵：自分のretroachievements.orgアカウントでログイン
• 実績を獲得して、リーダーボードで競い合おう
• パスワードは一度だけ使用され、保存されることはありません

📚 ライブラリ
• 検索、お気に入り、並べ替え
• ZIPファイルも解凍せずにそのまま使用可能
• 重複して保存されたゲームを見つけ、どちらのファイルを残すか確認
• カバーアートはオプション。オンにした場合のみダウンロード

ゲームは含まれていません
GBeeは、あなたが合法的に所有するゲームを、あなた自身のストレージから起動します。

プライバシー
GBeeには広告、分析ツール、独自のアカウントがなく、開発者がデータを受け取ることはありません。インターネットに接続するのは、ログイン後のRetroAchievements（ユーザー名とゲームの進行状況を受け取ります）と、オンにした場合のカバーアートの取得時のみです。

スクリーンショットは、GValienteによる無料のホームブリューゲーム「Butano Fighter」です。アートはPixel-boy（Sparklin Labs、CC0）によるものです。

GBAは任天堂の商標です。GBeeは任天堂と提携しておらず、任天堂の承認も受けていません。この名称は、GBeeがエミュレートするシステムを説明する目的でのみ使用しています。
```
