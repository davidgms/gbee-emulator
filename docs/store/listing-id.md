## Full description (2778/4000)

```
GBee adalah emulator GBA yang dibuat untuk ponsel, dipandu oleh GB, lebah berkacamata hitam. Tambahkan folder berisi game milikmu sendiri dan langsung main.

🎮 MAINKAN GAME GBA-MU
• Inti emulasi akurat yang ditulis dengan Rust, diuji dengan rangkaian uji perangkat keras publik
• Suara berlatensi rendah, dengan game berjalan di kecepatan penuh
• Percepat 2x, 4x, 8x, atau tanpa batas

🕹️ PINDAHKAN TOMBOL MANA PUN
• Geser dan ubah ukuran setiap tombol secara terpisah
• Tata letak terpisah untuk mode potret dan lanskap
• Simpan beberapa tata letak dan beralih di antaranya

🧩 BUAT TOMBOLMU SENDIRI
• Kombo: tekan beberapa tombol sekaligus dengan satu jari
• Urutan: ketuk tombol secara berurutan, satu per satu
• Tahan-lepas: ketuk sekali untuk menahan tombol, ketuk lagi untuk melepasnya

🎨 PILIH WARNAMU
• Tema tombol: Malam, Madu, Ungu, dan Abu-abu klasik
• Atur ukuran dan transparansi tombol agar pas di tanganmu
• Getaran di setiap tekanan

💾 SIMPAN DI MANA SAJA
• Simpan cepat dan muat cepat dari bilah atas
• 7 slot simpan tambahan, masing-masing dengan tanggal dan waktunya
• Putar balik: tahan tombol untuk mundur beberapa detik
• Lanjutkan game langsung dari simpan cepat
• Data simpanan game ditulis dengan aman, jadi crash atau memori ponsel yang penuh tidak bisa merusaknya
• Impor data simpanan dari emulator lain (.sav, .srm, .sa1) dan ekspor milikmu ke folder mana pun

✨ TAMPILANMU
• Filter layar: pixel perfect, halus, scanline CRT, dan 2xSaI
• Skala bilangan bulat untuk piksel yang tajam
• Frame blending, agar kedipan terlihat seperti di layar aslinya

🏆 RAIH PENCAPAIAN
• RetroAchievements terintegrasi: masuk dengan akun retroachievements.org milikmu sendiri
• Raih pencapaian dan bersaing di papan peringkat
• Kata sandimu hanya dipakai sekali dan tidak pernah disimpan

📚 PUSTAKAMU
• Pencarian, favorit, dan pengurutan
• File ZIP bisa langsung dipakai, tanpa perlu diekstrak
• Menemukan game yang tersimpan dua kali dan menanyakan file mana yang ingin dipertahankan
• Sampul game opsional, hanya diunduh jika kamu mengaktifkannya

TANPA GAME BAWAAN
GBee memainkan game yang kamu miliki secara sah, dari penyimpanan milikmu sendiri.

PRIVASI
GBee tidak punya iklan, analitik, atau akun sendiri, dan pengembang tidak menerima data apa pun. GBee hanya terhubung ke internet untuk RetroAchievements setelah kamu masuk (RetroAchievements menerima nama pengguna dan progres game-mu), dan untuk sampul game jika kamu mengaktifkannya.

Tangkapan layar menampilkan Butano Fighter, game homebrew gratis karya GValiente, dengan seni oleh Pixel-boy (Sparklin Labs, CC0).

GBA adalah merek dagang Nintendo. GBee tidak berafiliasi dengan Nintendo dan tidak didukung oleh Nintendo. Nama tersebut hanya digunakan untuk menjelaskan sistem yang diemulasikan oleh GBee.
```
