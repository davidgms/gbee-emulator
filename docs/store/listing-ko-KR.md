## Full description (1421/4000)

```
GBee는 휴대폰을 위해 만든 GBA 에뮬레이터로, 선글라스를 낀 꿀벌 GB가 안내합니다. 내 게임이 담긴 폴더를 추가하고 바로 플레이하세요.

🎮 GBA 게임 플레이
• Rust로 작성된 정확한 에뮬레이션 코어, 공개 하드웨어 테스트 스위트로 검증
• 지연이 적은 사운드와 최고 속도의 게임 플레이
• 2배, 4배, 8배 또는 무제한 빨리 감기

🕹️ 모든 버튼을 원하는 곳에
• 버튼을 하나씩 드래그하고 크기 조절
• 세로 모드와 가로 모드 레이아웃을 따로 설정
• 여러 레이아웃을 저장하고 전환

🧩 나만의 버튼 만들기
• 콤보: 한 손가락으로 여러 키를 동시에 누르기
• 시퀀스: 키를 순서대로 하나씩 입력
• 토글 홀드: 한 번 탭하면 키를 누른 상태로 유지, 다시 탭하면 해제

🎨 색상 선택
• 버튼 테마: 나이트, 허니, 바이올렛, 클래식 그레이
• 손에 맞게 버튼 크기와 불투명도 조절
• 누를 때마다 햅틱 피드백

💾 어디서나 저장
• 상단 바에서 빠른 저장과 빠른 불러오기
• 날짜와 시간이 표시되는 추가 저장 슬롯 7개
• 되감기: 버튼을 길게 눌러 몇 초 전으로 돌아가기
• 빠른 저장에서 바로 게임 이어 하기
• 게임 세이브는 안전하게 기록되어 앱이 비정상 종료되거나 저장 공간이 가득 차도 손상되지 않습니다
• 다른 에뮬레이터의 세이브 가져오기(.sav, .srm, .sa1) 및 원하는 폴더로 내보내기

✨ 나만의 화면
• 화면 필터: 픽셀 퍼펙트, 부드럽게, CRT 스캔라인, 2xSaI
• 선명한 픽셀을 위한 정수 배율 스케일링
• 프레임 블렌딩으로 깜빡임을 실제 화면처럼 표현

🏆 업적 달성
• RetroAchievements 내장: 내 retroachievements.org 계정으로 로그인
• 업적을 달성하고 리더보드에서 경쟁
• 비밀번호는 한 번만 사용되며 저장되지 않습니다

📚 내 라이브러리
• 검색, 즐겨찾기, 정렬
• ZIP 파일도 압축을 풀 필요 없이 바로 사용
• 두 번 저장된 게임을 찾아 어떤 파일을 남길지 물어봄
• 표지 이미지는 선택 사항이며, 켠 경우에만 다운로드

게임 미포함
GBee는 사용자가 합법적으로 소유한 게임을 사용자의 저장소에서 실행합니다.

개인정보 보호
GBee에는 광고, 분석 도구, 자체 계정이 없으며 개발자는 어떠한 데이터도 받지 않습니다. 인터넷 연결은 로그인한 후의 RetroAchievements(사용자 이름과 게임 진행 상황을 받습니다)와, 켠 경우 표지 이미지 다운로드에만 사용됩니다.

스크린샷은 GValiente가 만든 무료 홈브루 게임 Butano Fighter이며, 아트는 Pixel-boy(Sparklin Labs, CC0)의 작품입니다.

GBA는 닌텐도(Nintendo)의 상표입니다. GBee는 닌텐도와 제휴 관계가 없으며 닌텐도의 승인을 받지 않았습니다. 이 이름은 GBee가 에뮬레이트하는 시스템을 설명하기 위해서만 사용됩니다.
```
