## Full description (1040/4000)

```
GBee 是專為手機打造的 GBA 模擬器，由戴著墨鏡的蜜蜂 GB 帶路。加入存放自己遊戲的資料夾，就能開始遊玩。

🎮 暢玩你的 GBA 遊戲
• 以 Rust 撰寫的精準模擬核心，經過公開硬體測試套件驗證
• 低延遲音效，遊戲全速執行
• 快轉 2 倍、4 倍、8 倍或不限速

🕹️ 任意移動按鈕
• 每個按鈕都能單獨拖曳與調整大小
• 直向與橫向各有獨立的版面配置
• 保存多組版面配置並隨時切換

🧩 打造專屬按鈕
• 組合鍵：一指同時按下多個按鍵
• 連續鍵：依序逐一按下按鍵
• 切換按住：點一下即按住按鍵，再點一下放開

🎨 挑選你的配色
• 按鈕主題：夜晚、蜂蜜、紫羅蘭與經典灰
• 依你的手調整按鈕大小與透明度
• 每次按下都有震動回饋

💾 隨時隨地存檔
• 從頂端列快速存檔與快速讀檔
• 另有 7 個存檔欄位，各自標示日期與時間
• 倒轉：按住按鈕即可回到幾秒前
• 從快速存檔直接繼續遊戲
• 遊戲存檔會安全寫入，即使當機或手機空間不足也不會損毀
• 匯入其他模擬器的存檔（.sav、.srm、.sa1），也能將你的存檔匯出到任何資料夾

✨ 你的畫面風格
• 畫面濾鏡：像素完美、平滑、CRT 掃描線與 2xSaI
• 整數倍縮放，像素銳利清晰
• 影格混合，讓閃爍效果如同原本的螢幕

🏆 解鎖成就
• 內建 RetroAchievements：使用你自己的 retroachievements.org 帳號登入
• 解鎖成就，在排行榜上一較高下
• 密碼只會使用一次，絕不儲存

📚 你的遊戲庫
• 搜尋、我的最愛與排序
• 支援 ZIP 檔案，不必解壓縮
• 找出重複存放的遊戲，並詢問要保留哪個檔案
• 可選用封面圖，只有在你開啟後才會下載

不含任何遊戲
GBee 從你自己的儲存空間執行你合法擁有的遊戲。

隱私權
GBee 沒有廣告、沒有分析工具，也沒有自己的帳號系統，開發者不會收到任何資料。GBee 只會在你登入後連線至 RetroAchievements（它會收到你的使用者名稱與遊戲進度），以及在你開啟封面圖功能時連線下載封面。

截圖中的遊戲為 GValiente 製作的免費自製遊戲《Butano Fighter》，美術由 Pixel-boy（Sparklin Labs，CC0）繪製。

GBA 是任天堂（Nintendo）的商標。GBee 與任天堂無任何關聯，亦未獲任天堂認可。此名稱僅用於說明 GBee 所模擬的系統。
```
