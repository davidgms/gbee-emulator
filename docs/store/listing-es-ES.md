## Full description (2795/4000)

```
GBee es un emulador de GBA hecho para móviles, presentado por GB, una abeja con gafas de sol. Añade una carpeta con tus propios juegos y empieza a jugar.

🎮 JUEGA A TUS JUEGOS DE GBA
• Un núcleo de emulación preciso escrito en Rust, probado con baterías públicas de pruebas de hardware
• Sonido de baja latencia, con el juego a velocidad completa
• Avance rápido a 2x, 4x, 8x o sin límite

🕹️ MUEVE CUALQUIER BOTÓN
• Arrastra y cambia el tamaño de cada botón por separado
• Diseños distintos para vertical y horizontal
• Guarda varios diseños y cambia entre ellos

🧩 CREA TUS PROPIOS BOTONES
• Combo: pulsa varias teclas a la vez con un solo dedo
• Secuencia: toca las teclas en orden, una tras otra
• Mantener: toca una vez para dejar las teclas pulsadas y otra vez para soltarlas

🎨 ELIGE TUS COLORES
• Temas de botones: Noche, Miel, Violeta y Gris clásico
• Ajusta el tamaño y la opacidad de los botones a tus manos
• Vibración en cada pulsación

💾 GUARDA DONDE QUIERAS
• Guardado y carga rápidos desde la barra superior
• 7 ranuras de guardado más, cada una con su fecha y hora
• Rebobinar: mantén pulsado el botón para retroceder unos segundos
• Retoma una partida directamente desde tu guardado rápido
• Las partidas guardadas se escriben de forma segura, así que un cierre inesperado o un móvil sin espacio no pueden dañarlas
• Importa partidas de otros emuladores (.sav, .srm, .sa1) y exporta las tuyas a cualquier carpeta

✨ TU ESTILO
• Filtros de pantalla: pixel perfect, suave, scanlines CRT y 2xSaI
• Escalado entero para píxeles nítidos
• Fusión de fotogramas, para que el parpadeo se vea como en la pantalla original

🏆 GANA LOGROS
• RetroAchievements integrado: inicia sesión con tu propia cuenta de retroachievements.org
• Consigue logros y compite en las clasificaciones
• Tu contraseña se usa una sola vez y nunca se guarda

📚 TU BIBLIOTECA
• Búsqueda, favoritos y ordenación
• Funciona con archivos ZIP, sin necesidad de descomprimir
• Detecta un juego guardado dos veces y te pregunta qué archivo conservar
• Carátulas opcionales, que solo se descargan si las activas

NO INCLUYE JUEGOS
GBee ejecuta los juegos que posees legalmente, desde tu propio almacenamiento.

PRIVACIDAD
GBee no tiene anuncios, ni analíticas, ni cuentas propias, y el desarrollador no recibe ningún dato. Solo se conecta a internet para RetroAchievements, después de que inicies sesión (RetroAchievements recibe tu nombre de usuario y tu progreso en los juegos), y para las carátulas, si las activas.

Las capturas de pantalla muestran Butano Fighter, un juego homebrew gratuito de GValiente, con arte de Pixel-boy (Sparklin Labs, CC0).

GBA es una marca comercial de Nintendo. GBee no está afiliado a Nintendo ni cuenta con su respaldo. El nombre se usa solo para describir el sistema que GBee emula.
```
