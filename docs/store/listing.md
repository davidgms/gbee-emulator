## Full description (2249/4000)

```
GBee is a GBA emulator made for phones, hosted by GB, a bee in shades. Add a folder with your own games and start playing.

🎮 PLAY YOUR GBA GAMES
• An accurate emulation core written in Rust, tested against public hardware test suites
• Low-latency sound, with the game at full speed
• Fast forward at 2x, 4x, 8x or uncapped

🕹️ MOVE ANY BUTTON
• Drag and resize each button on its own
• Separate layouts for portrait and landscape
• Keep several layouts and switch between them

🧩 BUILD YOUR OWN BUTTONS
• Combo: press several keys at once with one finger
• Sequence: tap keys in order, one after another
• Toggle-hold: tap once to hold keys down, tap again to let go

🎨 PICK YOUR COLOURS
• Button themes: Night, Honey, Violet and Classic grey
• Set button size and opacity to fit your hands
• Haptic feedback on every press

💾 SAVE ANYWHERE
• Quick save and quick load from the top bar
• 7 more save slots, each with its date and time
• Rewind: hold the button to go back a few seconds
• Resume a game straight from your quick save
• Game saves are written safely, so a crash or a full phone cannot corrupt them
• Import saves from other emulators (.sav, .srm, .sa1) and export yours to any folder

✨ YOUR LOOK
• Screen filters: pixel perfect, smooth, CRT scanlines and 2xSaI
• Integer scaling for sharp pixels
• Frame blending, so flicker looks like it did on the real screen

🏆 EARN ACHIEVEMENTS
• RetroAchievements built in: sign in with your own retroachievements.org account
• Earn achievements and compete on leaderboards
• Your password is used once and never stored

📚 YOUR LIBRARY
• Search, favourites and sorting
• ZIP files work, no need to unzip
• Optional cover art, downloaded only if you turn it on

NO GAMES INCLUDED
GBee plays the games you legally own, from your own storage.

PRIVACY
GBee collects no data. It has no ads, no accounts of its own and no analytics. It goes online only for RetroAchievements after you sign in, and for cover art if you turn it on.

The screenshots show Butano Fighter, a free homebrew game by GValiente, with art by Pixel-boy (Sparklin Labs, CC0).

GBA is a trademark of Nintendo. GBee is not affiliated with or endorsed by Nintendo. The name is used only to describe the system that GBee emulates.
```
